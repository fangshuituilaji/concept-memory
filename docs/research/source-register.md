## 证据使用规则

1. 项目能力优先引用官方仓库/官方文档。
2. 方法和实验优先引用原始论文或会议版本。
3. Star、Fork、提交和 release 只作为随时间变化的活跃度信号，不作为质量证明。
4. 厂商自报 benchmark 记录为“厂商/项目报告”，需要在统一配置下独立复现。
5. 社区讨论只用于发现争议和风险，不用于支撑核心事实。
